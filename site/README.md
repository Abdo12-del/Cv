# بروفايل شخصي — موقع ثابت بلا أدوات بناء

**النسخة المنشورة:** <https://abdelkader-ammari.vercel.app>


بروفايل شخصي عربي (RTL) يجمع ثلاثة أدوار في هوية واحدة: معلّم أطفال، مؤسّس مبادرة تعليمية، وكاتب.
بُني بلا إطار عمل وبلا اعتماديات، اعتمادًا على `index.html` + CSS + وحدة JavaScript واحدة، ويقرأ كل المحتوى من ملف JSON واحد.

**شكل الواجهة:** صفحة شخص واحد، لا صفحة مؤسّسة ولا صفحة هبوط. خلفية زرقاء كاملة العرض من أعلى الصفحة، تضم الاسم والهوية المهنية وزر قائمة موحّدًا للهاتف وسطح المكتب. تتداخل بطاقة تعريف مختصرة مع حافة الخلفية، ثم يتابع المحتوى في تخطيط مرن من عمود واحد على الهاتف وعمودين عند اتساع المساحة.
الأقسام مرتبة كملفّ شخصي: الآن، المسار، المشاريع، المحتوى، الكتابة، ما أعود إليه، وتواصل؛ بلا شريط تنقّل مستقل أو أقسام مرقّمة.

## التشغيل

```bash
cd site
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`.

> لا تفتح `index.html` مباشرةً بنظام `file://`، لأن المتصفّح يمنع `fetch` لملف JSON في هذه الحالة.

## إضافة محتوى أو تعديله

كل النصوص والمنشورات والمشاريع في ملف واحد:

```
site/data/content.json
```

- **منشور جديد:** أضف كائنًا إلى `posts` بنفس الحقول (`id`, `slug`, `title`, `category`, `format`, `axis`, `cover`, `dek`, `sections`, `quote` اختياري).
  - `cover.motif`: `arcs | dots | lines | frame | wave | steps`
  - `cover.tone`: `paper | royal | navy | sky`
  - `cover.layout`: `stack | center | split | corner`
  - هذه القيم تنتج أغلفة طباعية داخلية، فلا حاجة إلى صور.
- **تصنيف جديد:** أضف عنصرًا إلى `categories`، ثم استخدم نفس المعرّف في `post.category`.
- **روابط التواصل:** املأ `profile.links[].href`؛ لا تظهر في الواجهة إلا الروابط الفعلية ذات العناوين المعبّأة.
- **الصورة الشخصية:** أضف صورة حقيقية داخل `[data-photo-slot]` في `index.html`؛ يبقى حرفا الاسم بديلًا عند عدم توفر صورة.
- **المشاريع:** أضف `published: true` لإظهار المشروع، واترك المشاريع غير الجاهزة على `published: false`. يمكن إضافة `image` و`imageAlt` للمعاينة، و`href` لرابط المشروع؛ لا يُنشأ أي منها تلقائيًا.
- **معلومات بطاقة التعريف:** `profile.meta` — مصفوفة `{ label, value }` تظهر داخل البطاقة (المجال، الحالة، …). المكان يُقرأ من `profile.location`.
- **قائمة «الآن»:** `ui.now` — مصفوفة `{ label, text }` (حتى ثلاثة أنصبة قصيرة عمّا تشتغل عليه اليوم).
- **عناوين الأقسام:** كلها في `ui` (`nowTitle`, `pathTitle`, `pathIntro`, `projectsTitle`, `projectsIntro`, `feedTitle`, `feedIntro`, `writingTitle`, `philosophyTitle`, `contactTitle`, `contactLead`) — لا نصوص مطبوعة في القوالب.

> يُدار محتوى الموقع من `data/content.json`. المشاريع التي تحمل `published: false` تبقى في ملف البيانات ولا تظهر للزوار؛ لا تُعرض صور أو روابط مشروع إلا عند إدخال أصول حقيقية.

## البنية

```
site/
├── index.html              # الهيكل الدلالي ونقاط التركيب
├── data/content.json       # كل المحتوى
└── assets/
    ├── fonts/              # Cairo وTajawal محليًا مع تراخيص OFL
    ├── css/
    │   ├── tokens.css      # الألوان والخطوط والمسافات والحركة
    │   ├── base.css        # إعادة الضبط، الترويسة، التذييل
    │   ├── components.css  # البطاقات، أغلفة المحتوى، النافذة
    │   └── sections.css    # تخطيط البروفايل والمشاريع والتواصل والاستجابة
    └── js/app.js           # تحميل المحتوى، الفلاتر، التفاصيل
```

## قرارات الهوية

- **بروفايل لا صفحة هبوط:** الاسم والهوية المهنية في المقدمة، والمحتوى مرتّب كملفّ عمل لا كعروض تسويقية.
- الخلفية الزرقاء متدرجة وتمتد بعرض الشاشة من أعلى الصفحة على جميع المقاسات؛ لا شريط مستقل فوقها. قائمة الأقسام تُفتح من زر داخل الهيرو.
- بطاقة التعريف البيضاء تتداخل مع حدّ الخلفية تداخلًا محدودًا، وتتحول الصفحة إلى عمود واحد على الشاشات الأصغر من 961px.
- الأبيض هو مساحة القراءة الأساسية؛ الأزرق الملكي `#0A5CC8` والكحلي `#004C99` يحافظان على الهوية والتباين.
- خطّان فقط: **Cairo** للعناوين و**Tajawal** للنصوص، مع بديل نظامي عربي.
- لا صور خارجية ولا شعارات؛ أغلفة المحتوى مولّدة من CSS وفق نظام: موتيف + لون + تكوين.
- الحركة 120–260ms وتحترم `prefers-reduced-motion`، وأهداف اللمس ≥44px على الهاتف.

## الوصول

- تجاوز إلى المحتوى، تباين نصّي مطابق، `focus-visible` واضح.
- النافذة `<dialog>` أصلية: حصر التركيز، وإغلاق بـ `Esc`، وتنقّل بالأسهم بين منشورات التصنيف نفسه.
- الفلاتر أزرار بحالة `aria-pressed` وعدّادات معلنة.

المشروع `abdelkader-ammari` مربوط بمستودع GitHub `Abdo12-del/Cv`، والجذر `site`.

- النشر التلقائي عند الدفع **معطّل** حاليًا (`createDeployments: disabled`)، فكل تحديث يحتاج نشرًا صريحًا. لتفعيله: Vercel → Project → Settings → Git → تفعيل النشر التلقائي.
- النشر من فرع `arena/30a1d11e-cv`؛ عند الدمج في `main` أعد النشر من الفرع الجديد.
