# بروفايل شخصي — موقع ثابت بلا أدوات بناء

**النسخة المنشورة:** <https://abdelkader-ammari.vercel.app>


بروفايل شخصي عربي (RTL) يجمع ثلاثة أدوار في هوية واحدة: معلّم أطفال، مؤسّس مبادرة تعليمية، وكاتب.
بُني بلا إطار عمل وبلا اعتماديات، اعتمادًا على `index.html` + CSS + وحدة JavaScript واحدة، ويقرأ كل المحتوى من ملف JSON واحد.

**شكل الواجهة:** صفحة شخص واحد، لا صفحة مؤسّسة ولا صفحة هبوط. بطاقة تعريف ثابتة على اليمين (صورة دائرية + اسم + أدوار + روابط)،
وتيار أقسام على اليسار يقرأ كملفّ شخصي: نبذة، الآن، المسار، المشاريع، المحتوى، الكتابة، ما أعود إليه، تواصل.
لا هيرو تسويقي، لا أزرار دعوة إلى إجراء، لا أقسام مرقّمة (`01 / 02 / 03`)، ولا أشرطة خلفية متبادلة: فواصل شعرية فقط.

## التشغيل

```bash
cd site
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`.

> لا تفتح `index.html` مباشرةً بنظام `file://`، لأن المتصفّح يمنع `fetch` لملف JSON في هذه الحالة.

## إضافة محتوى أو تعديله

كل النصوص والمنشورات والمشاريع في ملف واحد:

```
site/data/content.json
```

- **منشور جديد:** أضف كائنًا إلى `posts` بنفس الحقول (`id`, `slug`, `title`, `category`, `format`, `axis`, `cover`, `dek`, `sections`, `quote` اختياري).
  - `cover.motif`: `arcs | dots | lines | frame | wave | steps`
  - `cover.tone`: `paper | royal | navy | sky`
  - `cover.layout`: `stack | center | split | corner`
  - هذه القيم تنتج أغلفة طباعية داخلية، فلا حاجة إلى صور.
- **تصنيف جديد:** أضف عنصرًا إلى `categories`، ثم استخدم نفس المعرّف في `post.category`.
- **روابط التواصل:** املأ `profile.links[].href`؛ الروابط الفارغة تُعرض كعناصر «قريبًا» بلا رابط.
- **الصورة الشخصية:** استبدل عنصر `[data-photo-slot]` في `index.html` بصورة حقيقية داخل إطار دائري (لا يوجد حاليًا سوى حرفين بديلين).
- **صفوف بطاقة التعريف:** `profile.meta` — مصفوفة `{ label, value }` تظهر تحت الاسم (المجال، الحالة، …). المكان يُقرأ من `profile.location`.
- **قائمة «الآن»:** `ui.now` — مصفوفة `{ label, text }` (حتى ثلاثة أنصبة قصيرة عمّا تشتغل عليه اليوم).
- **عناوين الأقسام:** كلها في `ui` (`introTitle`, `nowTitle`, `pathTitle`, `pathIntro`, `projectsTitle`, `projectsIntro`, `feedTitle`, `feedIntro`, `writingTitle`, `philosophyTitle`, `contactTitle`, `contactLead`) — لا نصوص مطبوعة في القوالب.

> المحتوى الحالي **تجريبي** (`meta.contentStatus = "sample"`) وكُتب لاختبار النظام البصري، وليس منشورًا حقيقيًا. يُستبدل بالكامل من JSON دون تعديل الكود.

## البنية

```
site/
├── index.html              # الهيكل الدلالي ونقاط التركيب
├── data/content.json       # كل المحتوى
└── assets/
    ├── css/
    │   ├── tokens.css      # الألوان والخطوط والمسافات والحركة
    │   ├── base.css        # إعادة الضبط، الترويسة، التذييل
    │   ├── components.css  # البطاقات، الأغلفة، المشاريع، النافذة
    │   └── sections.css    # تخطيط البروفايل (العمود + التيار) والاستجابة
    └── js/app.js           # تحميل المحتوى، الفلاتر، التفاصيل
```

## قرارات الهوية

- **بروفايل لا صفحة هبوط:** الاسم هو أكبر عنصر في الصفحة، والصورة الشخصية هي نقطة الدخول، والمحتوى مرتّب كملفّ عمل لا كعروض تسويقية.
- خلفية بيضاء/فاتحة هي الأصل؛ الأزرق الملكي `#0A5CC8` للتركيز فقط، والكحلي `#004C99` للنصوص المهمّة.
- التدرّج بين `#0A5CC8` و`#2A8DF0` محصور في شريط علوي واحد (3px).
- خطّان فقط: **Cairo** للعناوين و**Tajawal** للنصوص، مع بديل نظامي عربي.
- لا صور خارجية ولا شعارات؛ أغلفة المحتوى مولّدة من CSS وفق نظام: موتيف + لون + تكوين.
- الحركة 120–260ms وتحترم `prefers-reduced-motion`، وأهداف اللمس ≥44px على الهاتف.

## الوصول

- تجاوز إلى المحتوى، تباين نصّي مطابق، `focus-visible` واضح.
- النافذة `<dialog>` أصلية: حصر التركيز، وإغلاق بـ `Esc`، وتنقّل بالأسهم بين منشورات التصنيف نفسه.
- الفلاتر أزرار بحالة `aria-pressed` وعدّادات معلنة.
