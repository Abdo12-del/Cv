## حدود المنهجية (اقرأها قبل الاقتباس)

1. **لا محرّك رسم:** الحركة، الـ hover، الـ scroll، الموبايل والأداء **لم تُختبر**. كل ذلك معلَّم `N/V` أو `[غير متحقق]`.
2. **لا أرقام مخترعة:** كل درجة مذكورة مصدرها Awwwards أو CSS Design Awards أو تحقّق تقني/بصري.
3. **لا ملكية:** جميع المواقع والصور واللوحات مملوكة لأصحابها؛ هذا المجلد للدراسة فقط.
4. **ثلاثة مواقع لم تُفتح:** `micheledu.com` (كلمة مرور)، `cosmos.so` (403)، `activetheory.net` (500) — مذكورة ولا تُحتسب.
