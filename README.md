# الموقع الشخصي — عبد القادر عماري

بروفايل شخصي عربي (RTL) — واجهة صفحة شخص واحد لا صفحة مؤسّسة: غلاف أزرق ممتد مع تنقّل مدمج + بطاقة تعريف بعرض المحتوى + تيار أقسام (نبذة، الآن، المسار، المشاريع، المحتوى، الكتابة، تواصل).
لمعلّم أطفال، ومؤسّس أكاديمية تعليمية، وكاتب. التصميم مبنيّ من الصفر، والمحتوى مفصول عن الكود داخل ملف بيانات واحد.

**النسخة المنشورة:** <https://abdelkader-ammari.vercel.app>

> المحتوى الحالي تجريبي ومعلَّم كذلك داخل الصفحة، والصورة الشخصية وروابط التواصل بحاجة إلى بيانات صاحب الموقع.

## ما داخل المستودع

| المسار | الوصف |
|---|---|
| `site/` | الموقع نفسه: HTML + CSS + JavaScript بدون أي خطوة بناء |
| `research/` | دراسة مرجعية للهوية البصرية والمحتوى على الشبكات الاجتماعية (مرحلة بحث) |
| `web-ui-research/` | دراسة مرجعية لواجهات المواقع والبورتفوليو والحركة (مرحلة بحث) |

## التشغيل محليًا

```bash
cd site
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`. لا حاجة إلى `npm install` ولا إلى أي أدوات بناء — الملفات تُقدَّم كما هي.

## بنية الموقع

```
site/
├── index.html          بروفايل: بطاقة تعريف متداخلة مع الغلاف + تيار أقسام (نبذة، الآن، المسار، المشاريع، المحتوى، الكتابة، تواصل)
├── data/content.json   كل النصوص والتصنيفات والمشاريع والروابط
├── assets/css/         tokens · base · components · sections
├── assets/js/app.js    العرض، التصفية، لوحة التفاصيل، الروابط العميقة
└── README.md           دليل التسليم: إضافة منشور أو مشروع، وقرارات الهوية، والوصولية
```

## إضافة محتوى

كل شيء يُضاف من `site/data/content.json` دون تعديل الكود: منشورات (`posts`)، مشاريع (`projects`)، كتابة (`writing`)، مسار (`timeline`)،
صفوف بطاقة التعريف (`profile.meta`)، وقائمة «الآن» (`ui.now`)، وعناوين الأقسام (`ui.*`). الشرح الكامل وحقول الأغلفة (`motif` / `tone` / `layout`) في [`site/README.md`](site/README.md).

## الهوية البصرية

خلفية بيضاء مهيمنة، أزرق ملكي `#0A5CC8` للتركيز فقط، كحلي `#004C99` للنصوص المهمّة، وخطّان فقط: Cairo وTajawal. لا رسوم متحركة معقّدة أو تدرّجات في الغلاف؛ زخارف دائرية وحدود وظلال خفيفة.

**الواجهة بروفايل لا صفحة هبوط:** لا هيرو تسويقي، لا أزرار «ابدأ الآن»، لا أقسام مرقّمة، ولا أشرطة CTA — فواصل شعرية وعناوين قصيرة بشرطة زرقاء واحدة.

## النشر

النشر الحالي على **Vercel** من مجلد `site` بلا خطوة بناء (تفاصيل الإعدادات في `site/README.md`). يمكن أيضًا نشر المجلد على أي استضافة ملفات ثابتة، بما في ذلك GitHub Pages إن رغبت بذلك لاحقًا.

## الترخيص

جميع الحقوق محفوظة لصاحب الموقع. النصوص والتصميم ليسا للاستخدام التجاري دون إذن.

## تحديث التخطيط المتجاوب (نسخة الحاسوب + الهاتف)

- **نسخة الحاسوب (`>= 860px`):** تخطيط مكتبي من عمودين غير متناظرين (RTL)؛ تستقر بطاقة التعريف الشخصية وصورتها محاذيتين لليمين ضمن عمود جانبي ثابت أثناء التمرير بدل توسيطهما وسط الشاشة، وتمتد أقسام البروفايل في مساحة عمل رحبة على اليسار شبكيًا («الآن» بثلاث بطاقات أفقية، «المسار» بشبكة 2×2، «المشاريع» ببطاقات مقسومة أفقيًا، «المحتوى» بشبكة ثلاثية مع شريط فلاتر علوي، «ما أعود إليه» بمصفوفة 2×2، و«تواصل» بكتلة مزدوجة).
- **نسخة الهاتف واللوحي العمودي (`< 860px`):** تحافظ على تخطيط الهاتف المدمج والمتوسّط مع قائمة منسدلة واضحة التباين وشريط علوي زجاجي عند التمرير.
- **الخطوط:** مستضافة محليًا (`site/assets/fonts`) بصيغة `woff2` لخطَّي Cairo وTajawal لضمان عرض فوري دون اعتماد خارجي.
