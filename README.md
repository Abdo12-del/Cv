# الموقع الشخصي — عبد القادر عماري

بروفايل شخصي عربي باتجاه RTL، يجمع أدوار معلّم الأطفال ومؤسّس الأكاديمية التعليمية والكاتب. يبدأ بخلفية زرقاء كاملة العرض تضم الاسم والهوية المهنية والتنقّل، ثم بطاقة تعريف متداخلة وتدفّق أقسام عن العمل والمسار والمشاريع والكتابة والتواصل.

**النسخة المنشورة:** <https://abdelkader-ammari.vercel.app>

## ما داخل المستودع

| المسار | الوصف |
|---|---|
| `site/` | الموقع نفسه: HTML وCSS وJavaScript بلا خطوة بناء |
| `research/` | دراسة مرجعية للهوية البصرية والمحتوى |
| `web-ui-research/` | دراسة مرجعية لواجهات المواقع والبورتفوليو والحركة |

## التشغيل محليًا

```bash
cd site
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000`. لا حاجة إلى `npm install` أو أدوات بناء؛ الملفات ثابتة.

## بنية الموقع

```
site/
├── index.html          الهيكل الدلالي والهيرو وقائمة التنقّل والأقسام
├── data/content.json   النصوص والتصنيفات والمشاريع والروابط
├── assets/css/         tokens · base · components · sections
├── assets/js/app.js    العرض والتصفية وقائمة التنقّل وتفاصيل المحتوى
└── README.md           دليل المحتوى والتصميم والوصولية
```

تُدار المشاريع من `site/data/content.json`. المشاريع التي تحمل `published: false` تبقى في البيانات ولا تظهر للعامة؛ لا تظهر إلا المشاريع المنشورة. يمكن إضافة معاينة حقيقية عبر `image` و`imageAlt`، ورابط فعلي عبر `href`، ولا تُنشأ صور أو روابط تلقائيًا. التفاصيل في [`site/README.md`](site/README.md).

## الهوية والاستجابة

اللونان الأزرق والأبيض أساس التصميم، مع خطّي Cairo وTajawal المستضافين محليًا. الخلفية الزرقاء تمتد بعرض الشاشة من أعلى الصفحة؛ وتُفتح قائمة الأقسام من زر داخل الهيرو على الهاتف وسطح المكتب. التخطيط عمود واحد على الشاشات الصغيرة، ويتحوّل إلى عمودين عندما تسمح المساحة بذلك، مع دعم RTL.

## النشر

النشر على **Vercel** من مجلد `site` بلا خطوة بناء. ويمكن نشر المجلد نفسه على أي استضافة ملفات ثابتة.

## الترخيص

جميع الحقوق محفوظة لصاحب الموقع. النصوص والتصميم ليسا للاستخدام التجاري دون إذن.
